One Page Formula & Concept Sheet • Exam Night Revision

Process: Program + PCB + Address Space + Resources
PCB Fields: PID, PC, Registers, State, Memory, Files, Accounting
Syscalls: fork, exec, wait, exit, open, read, write
Von Neumann: Fetch→Decode→Execute→Store, PC→IR→ALU
Modes: User mode (restricted), Kernel mode (full power), Trap switches
LDE: Direct execution + Timer interrupt = Fast + Safe
Memory Trick: UALOKDFH for stack layers
Exam Tip: Always draw diagram, write 2 examples (Linux + Mobile), mention advantages
