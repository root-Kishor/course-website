1. TYPES OF DATA — The Foundation of Everything

What is data, why classification matters, qualitative, quantitative, ranked, structured, semi-structured, unstructured — with industry examples, memory tricks, infographics and 15 MCQs.

▼
🎯 Learning Objectives
  • Define data in simplest English
  • Classify data into 7 major types
  • Differentiate structured vs unstructured with real examples
  • Answer Anna University 2,5,10 mark questions
📋 Prerequisites

No statistics needed. Only know that a computer stores information. That's it.

🌟 Learning Outcomes

After this you can look at any dataset (Instagram comments, Excel sheet, CCTV footage) and instantly say its type.

1️⃣ Simple English Explanation

What is Data?

Data = Any fact that you can record. Your name is data. Your height 5'6" is data. The photo you just took is data. The temperature 32°C is data. In Data Science, we say: Data is the raw material. Information is the finished product.

🧠 Daily Life Analogy

Think of a kitchen. Vegetables, rice, spices = Data. The cooked biryani = Information. Without classifying vegetables (which is leafy, which is root), you can't cook well. Same with data.

💼 Why We Need Classification?

Because different data needs different tools. You can't take average of colours. You can't make pie chart of temperature easily if you don't know type. Wrong classification = wrong algorithm = failed interview.

📚 The 7 Types — Full Breakdown

A • Qualitative Data (Categorical)

Data that describes QUALITY, not number

Simple: Answers What kind? Which category?

Examples: Gender (Male/Female), Blood Group (A,B,O), City (Chennai, Mumbai), Customer Review (Good/Bad)

Industry: Netflix uses qualitative data — Genre = Comedy, Drama.

⚠ Common Mistake: Students think A+, B+ grades are numbers. They are categories!

Memory Trick: QUALitative = QUALity = Describes.

B • Quantitative Data (Numerical)

Data that is COUNTABLE or MEASURABLE

Simple: Answers How many? How much?

Examples: Age=20, Marks=85, Salary=₹50k, Height=172cm

Industry: Amazon — Price, Number of items sold — used for prediction.

Memory Trick: QUANTitative = QUANTITY = Number.

C • Ranked Data

Data with an ORDER, but difference not equal

Example: 1st Rank, 2nd Rank in class. Movie rating: 1 Star to 5 Stars. Satisfaction: Very Bad < Bad < Good < Very Good. We know order, but gap between Good and Very Good is not fixed like numbers.

Daily Life: Your Swiggy delivery rating.

D • Structured Data

Data in perfect rows and columns — Excel style

Example: Student table: Roll No | Name | Marks. 80% of company data is structured. Easy to store in SQL.

E • Semi-Structured Data

Not full table, but has tags

JSON, XML, Email (To, Subject, Body), CSV with some missing fields. Has some structure, but not rigid.

Industry: Every API you use returns JSON — that is semi-structured.

F • Unstructured Data

No rows, no columns — wild data

Photos, Videos, Audio, Tweets, Instagram Reels, PDF resumes. 80-90% of world data is unstructured! Needs AI to understand.

Industry: YouTube thumbnails, CCTV footage for self-driving cars.

CHAPTER 02⏱ 60 min

2. TYPES OF VARIABLES — The Alphabet of Data Science

Variable vs Constant, Independent vs Dependent vs Confounding, Discrete vs Continuous, Nominal Ordinal Interval Ratio — with comparison tables and memory maps.

▼
Beginner Zero Level

Variable = Anything that can CHANGE. Constant = Never changes. In a class, Student Marks = Variable (changes per student). Value of Pi = 3.1415 = Constant. In formula y = mx + c, x,y = Variables, m,c = constants for that line.

Independent Variable

The CAUSE. You control it. Example: Hours Studied (you decide). It does NOT depend on others.

Memory: Independent = I am free, I don't depend.

Dependent Variable

The EFFECT. Result. Example: Marks depend on hours studied. Salary depends on experience.

Daily life: Number of rotis you eat (independent) → Stomach fullness (dependent).

Confounding Variable

Hidden villain. Example: You study more → marks up, but also Coffee you drink increased. Is coffee confounding? It mixes the effect. In research, we must control it.

Discrete vs Continuous — Most Asked
DiscreteContinuous
Countable, gap exists. Example: Number of students = 40, can't be 40.5Measurable, can be any decimal. Height = 172.5 cm possible
Graph: Bar onlyGraph: Histogram, line
Memory: Discrete = Digital clicks (tik tik)Continuous = Water flow (smooth)
Categorical vs Numerical

Mnemonic for NOIR scale (Nominal Ordinal Interval Ratio):
“Noodles Ordered In Restaurant”

CHAPTER 03

3. DESCRIBING DATA WITH TABLES — Frequency Magic

Grouped vs Ungrouped, Relative, Cumulative, Percentage, Percentile Rank, Quartiles, Outliers — step-by-step table construction.

▼
What is Frequency?

Frequency = How many times something appears. Example: Marks: [50,60,60,70,70,70]. Frequency of 70 = 3. Simple.

Ungrouped Frequency

When data is small, list each value. Example: Shoes size: 7 appears 2 times, 8 appears 5 times.

Grouped Frequency

When data is large (0-100 marks), group into classes: 0-10, 10-20, etc. Saves space.

Relative Frequency

Relative = Frequency / Total. Example: 3 out of 10 students got 70 → Relative = 3/10 = 0.3 = 30%

Formula: RF = f / N

Cumulative Frequency

Running total. Example: Marks ≤60 = how many students? Add frequencies till that class.

Use: To find median, quartiles quickly.

Outliers & Percentile

Outlier: Very different value (most students 50-70, one 5). Spoils mean. Percentile Rank: If you are 90th percentile, you beat 90% students. Quartiles: Data cut into 4 equal parts — Q1=25%, Q2=50% (Median), Q3=75%.

4. DESCRIBING DATA WITH GRAPHS — Visual Storytelling

Histogram, Bar, Frequency Polygon, Stem-Leaf, Pie, Line, Scatter, Box Plot — when to use, when NOT to use, common mistakes.

▼
Histogram

For Continuous data, bars TOUCH each other

Purpose: Show distribution of marks. Construction: X = class interval, Y = frequency. No gap. When NOT: Don't use for categorical (use bar).

Bar Graph

For Categorical data, bars have GAP

Example: Number of students per department. Bars separated. Advantage: Easy to compare. Common Mistake: Students draw histogram for blood groups — wrong! Use bar.

Frequency Polygon & Pie Chart

Polygon = Line joining midpoints of histogram

Shows trend. Pie = Circle divided into %. Use when parts of whole (market share). Limit: Don't use pie for >5 categories — becomes messy.

Box Plot & Scatter

Box Plot = 5 number summary visual

Shows Min, Q1, Median, Q3, Max + Outliers. Best for outlier detection. Scatter Plot = Shows relationship between 2 variables (Height vs Weight). If dots go up = Positive correlation.

5. DESCRIBING DATA WITH AVERAGES — Mean, Median, Mode

Central Tendency demystified from zero — formulas, step-by-step numericals, weighted mean, which average when?

▼
Simple English

Average = One number that represents whole group. If 5 friends have pocket money 10,20,30,40,50 → Average 30 represents them. We have 3 averages:

  • Mean: Add all ÷ count (most common)
  • Median: Middle value when sorted
  • Mode: Most frequent value
Mean — Formula

Population Mean: μ = Σx / N
Sample Mean: x̄ = Σx / n
Weighted Mean: Σ(w·x)/Σw

Example: 2,4,6 → Mean = (2+4+6)/3=4

When to use: Data has no outlier, need precise center.

Limitation: Outlier spoils mean (1,2,3,100 → mean 26.5 wrong, median 2.5 better)

Median — Middle

Steps: Sort → If odd n, middle. If even, average of 2 middles.

Ex: 5,2,9,1,7 → Sorted 1,2,5,7,9 → Median=5
Ex: 1,2,3,4 → (2+3)/2=2.5

Advantage: Not affected by outlier. Best for salary data (few CEOs high salary).

Mode — Most Frequent

Data: 2,3,3,4,5,3 → Mode=3 (appears 3 times). Can have 2 modes (bimodal). If all unique, no mode.

Use: Categorical data — Most common blood group? Mode.

CHAPTER 06

6. DESCRIBING VARIABILITY — How Spread is Data?

Range, Variance, Standard Deviation, IQR, Degrees of Freedom, Sum of Squares — formulas in simple English with units and visuals.

▼
Why Variability? Story

Two classes both have mean 70 marks. Class A: 68,69,70,71,72 (all near mean — consistent). Class B: 20,40,70,90,130 (spread — inconsistent). Mean same, but performance very different! So we need spread measures.

Range

Simple: Max - Min. Example: 10,20,30 → Range=20. Advantage: Easy. Limitation: Only uses 2 values, outlier spoils.

Interquartile Range (IQR)

IQR = Q3 - Q1. Middle 50% spread. Example: Q1=30, Q3=70 → IQR=40. Not affected by outlier. Used in Box Plot to find outliers: Outlier if < Q1-1.5*IQR or > Q3+1.5*IQR

Variance — The Heart

Variance = Average of squared distances from mean. Steps: 1) Find mean 2) Find (x - mean)² for each 3) Average them.

Population: σ² = Σ(x-μ)² / N
Sample: s² = Σ(x-x̄)² / (n-1)

Unit: Square of original (if marks, variance unit = marks²). That's why we need SD.

Memory: Variance = Variation + Dance? Actually how much data dances away from mean.

Standard Deviation — Star of Exam

SD = √Variance. Brings unit back to original. Most important spread measure.

Interpretation: If mean=50, SD=5 → most students 45-55. If SD=20 → marks spread 30-70 → high variability.

Formula: σ = √(Σ(x-μ)² / N)

Industry: Stock market — high SD = risky stock.

CHAPTER 07

7. NORMAL DISTRIBUTION — The Bell Curve of Nature

Properties, Bell Curve, Mean=Median=Mode, Skewness, Applications in ML and Industry — animated SVG bell curve.

▼
What is Normal Distribution?

Simple: When you plot height of 1000 students, you get a bell shape — most near average, few very tall, few very short. That's Normal Distribution. Nature loves this shape!

Properties (Must Memorize)
  • Bell shaped, symmetric
  • Mean=Median=Mode same at center
  • 68-95-99.7 Rule: 68% data within 1σ, 95% within 2σ, 99.7% within 3σ
  • Total area = 1 (100%)
  • Tails never touch zero — extends to infinity

Memory Trick: “68-95-99.7” — Remember phone number 68 95 99 — Normal is “normal phone”.

Skewness

Skew = Tilt. Normal = No skew (0).
Positive skew (Right): Tail to right → Mean > Median. Example: Salary (few rich pull mean right).
Negative skew (Left): Tail left → Mean < Median. Example: Age of retirement — few early retirement pull left.

🌍 Industry & ML Uses

Real Life: Height, Weight, BP, IQ, Errors in measurement — all normal.
Industry: Quality control — If product weight not normal, machine faulty.
Machine Learning: Many algorithms assume data is normal (Linear Regression, Naive Bayes). So we check normality and transform if not normal. In AI, weight initialization uses normal distribution!

8. STANDARD (Z) SCORES — The Universal Translator

What is Z, why needed, formula, interpretation, Z-table, probability, finding original score — full worked examples.

▼
Simple Explanation — Daily Life Analogy

Two students: A scored 80 in Maths (class mean 70, SD 10). B scored 85 in English (mean 80, SD 5). Who performed better relative to class? Raw marks B higher, but let's convert to Z.

Z = (Your Score - Mean) / SD = How many SDs away from mean.

A: (80-70)/10=1 → 1 SD above mean.
B: (85-80)/5=1 → Also 1 SD above! Both equal! Z makes different exams comparable.

Daily Analogy: Like converting dollars and rupees to a common currency to compare wealth. Z is common currency for data.

Formula & Interpretation

Z = (X - μ) / σ

  • Z=0 → Exactly at mean
  • Z=+2 → 2 SD above mean (excellent)
  • Z=-1.5 → 1.5 SD below mean
  • Z between -3 to +3 is normal

Positive Z = Above mean, Negative = Below.

Z-Table & Probability

Z-table tells area under curve. Example: Z=1 → Area 0.8413 → 84.13% scored below you, 15.87% above. Used for probability, cutoff, grading.

Finding Original Score: X = μ + Z·σ. If Z=2, μ=50, σ=10 → X=70.

Solved Example — Step-by-Step

Q: Mean=100, SD=15. Find Z for X=130. What % below?
Z=(130-100)/15=2. Table: 0.9772 → 97.72% below, top 2.28%.

Q: Top 10% cutoff? Find X such that 90% below.
Z for 0.90 ≈1.28. X=100+1.28*15=119.2. So 119+ is top 10%.

🧠 Memory Trick

“Zee = Zero to Hero measure”. Z tells how hero you are from average. Formula: (You - Average)/Spread.

Exam Tip: Always draw bell curve, mark mean, shade area asked. Half marks for diagram in Anna University!
